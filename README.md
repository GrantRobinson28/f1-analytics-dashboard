# Formula 1 Performance Analytics Dashboard
An interactive Tableau dashboard suite that turns decades of Formula 1 racing data into clear visual stories — comparing drivers' careers, reliability, and performance at a glance.

## Overview
This project visualizes the career trajectories and performance of top Formula 1 drivers, making complex historical racing data accessible to a non-technical audience. It combines several raw data sources into a single, interactive view designed around clear visual storytelling.

## Data
- Source: [Formula 1 Official Data (1950–2022) on Kaggle](https://www.kaggle.com/datasets/debashish311601/formula-1-official-data-19502022)
- Aggregated and cleaned from 14 raw CSV files into a unified set of tables for analysis, with calculated fields for metrics like win percentage and cumulative points

## What the Dashboard Shows
- **Driver career trajectories** and performance metrics over time
- **Head-to-head driver comparisons**
- **Podium-finish ratios**
- **"Did Not Finish" (DNF) reliability analysis**
- Visuals designed to let users compare driver consistency across different eras

## Tech Stack
Tableau · data cleaning · data visualization · visual storytelling

## Repository Contents
- `F1_Performance_Analytics_Dashboard.twbx` — packaged Tableau workbook

## How to View
1. Install [Tableau Desktop](https://www.tableau.com/products/desktop) or the free [Tableau Reader](https://www.tableau.com/products/reader).
2. Open the `.twbx` workbook.
3. Interact with the filters and views to explore drivers, eras, and reliability.
